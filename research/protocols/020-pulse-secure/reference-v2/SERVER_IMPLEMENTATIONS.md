# Server implementations — Pulse Secure

Canonical historical product: Pulse Connect Secure; maintained successor name: Ivanti Connect Secure (ICS). The gateway is proprietary. Current reviewed vendor anchors are ICS 22.8R2.3 build 18655 and the 25.x-compatible client matrix. No public source tree/license is claimed.

OpenConnect/ocserv is not a Pulse server: ocserv implements the AnyConnect family and must not be listed as a server replacement for Pulse.

Deployment roles: hardware ISA appliances, vendor virtual appliance, clustered/HA gateway. Vendor documentation is authoritative for supported platforms and licensing.
