# Client install matrix

Vendor client lineage: Pulse Secure Client -> Ivanti Secure Access Client (ISAC), proprietary.

Current reviewed desktop reference is ISAC 22.8R7 build 48847. Qualified desktop environments include current Windows 11, macOS Tahoe/Sequoia/Sonoma and Linux distributions including Ubuntu 22.04/24.04, Debian 12/13, Fedora 42/43, RHEL 9/10 and CentOS 9 as listed by Ivanti. Exact builds change by release and must not be generalized beyond the vendor table.

Mobile is separately packaged and versioned. Current 22.8.7 platform guide lists iOS and Android plus ChromeOS via Android client, with current qualified device/OS matrices and compatible ICS gateway releases. Android TV/Google TV is not documented as a qualified target and is therefore unknown/unsupported for this entry rather than inferred from Android phone support.

Vendor downloads may require authenticated Software Download Portal access; mobile clients use platform application stores.

Sources: https://help.ivanti.com/ps/help/en_US/ISAC/22.X/spg-22.X/platform-and-browser-compatibility.htm ; https://help.ivanti.com/ps/help/en_US/ISAC/22.X/spg-mobile-22.8.7/client_compatibility.htm
