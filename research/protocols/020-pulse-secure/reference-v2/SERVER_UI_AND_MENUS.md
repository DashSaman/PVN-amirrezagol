# Server UI and menus

Current Ivanti Connect Secure admin documentation provides the recoverable menu map for the historical Pulse Connect Secure product line.

Key areas: Dashboard/Reports; Users > User Realms and User Roles; Users > Resource Policies > VPN Tunneling (Access Control, Connection Profiles, Split Tunneling); System > Configuration (network/security/licensing); System > Log/Monitoring; authentication realms/servers and role mapping; certificates/security; clustering; administrators/delegated roles; maintenance/configuration import-export; troubleshooting tools; integrations/Neurons/Pulse One where release-applicable.

VPN profile policy controls include address assignment, transport/encryption choices, split/full tunnel, DNS/routing and auto-launch/auto-uninstall options. Logging covers Events, User Access, Admin Access and client-side VPN tunneling collection; syslog supports UDP/TCP/TLS.

Sources: https://help.ivanti.com/ps/help/en_US/ICS/22.x/ag/Default.htm ; https://help.ivanti.com/ps/help/en_US/ICS/22.x/vtcg/configuring-vpn-tunneling.htm ; https://help.ivanti.com/ps/help/en_US/ICS/22.x/22.8R2/ag/logging_n_monitoring.htm
