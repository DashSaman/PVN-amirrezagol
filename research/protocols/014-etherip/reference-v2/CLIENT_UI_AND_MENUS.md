# EtherIP — Peer UI / Menu Map

Review date: 2026-08-14 UTC

There is no canonical consumer-client UI. Applicable peer/operator controls are evidence-backed infrastructure fields:

- local/remote outer IP endpoints;
- EtherIP interface/service state;
- bridge or Virtual Hub attachment;
- SoftEther client-ID mapping and mapping target;
- up/down/reconnect state;
- frame/byte/interface counters when the selected implementation exposes them;
- MTU/path diagnostics;
- firewall/policy warning;
- security badge: `RAW ETHERIP — NO INTEGRATED ENCRYPTION`.

Secrets in SoftEther mappings remain server-secret state and must be redacted. A mobile QR/subscription/profile screen is N/A and must not be fabricated.
