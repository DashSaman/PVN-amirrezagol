# 043 Hysteria2 — client install matrix

Reviewed: 2026-08-15

Official `app/v2.12.1` release supplies broad platform/architecture binaries including Android, Darwin, Linux, Windows and other release targets. Official binary/core is the primary client reference.

Client source/config supports local SOCKS5, HTTP, TCP/UDP forwarding, Linux TProxy/redirect and TUN-family operation with platform-specific restrictions. Android/Apple GUI wrappers and multi-protocol clients are independent products with separate licenses/Store/runtime constraints; no wrapper is treated as canonical merely for supporting a Hysteria2 URI/profile.

Store receipts, system-extension/VPN permission behavior and real-device matrices remain later certification work.
