# 047 NaiveProxy — client install matrix

Official upstream current release provides desktop/server-style Naive binaries across major Windows/Linux/macOS architectures and Android plugin APKs with SHA-256 digests. Upstream also names OpenWrt and Android host integrations.

GUI reference: `2dust/v2rayN` GPL-3.0 has dedicated Naive profile format/import/core plumbing and sing-box outbound mapping; closed/mobile hosts named upstream are behavioral references only.

No claim is made that every Chromium-supported platform has a Naive binary. Exact APK host compatibility, Store lifecycle, Android VPN service and device results remain later certification.
