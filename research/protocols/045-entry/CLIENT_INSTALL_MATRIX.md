# 045 AnyTLS — client install matrix

Reviewed: 2026-08-15

- anytls-go v0.0.13: official Windows/Linux/macOS amd64/arm64 client binaries; source licensing unresolved.
- sing-box: serious cross-platform open-source AnyTLS implementation under GPLv3-or-later plus additional condition.
- Throne: GPL-3.0 desktop GUI with dedicated AnyTLS profile/config/persistence source paths (`edit_anytls`, outbound factory/database/subscription integration).
- upstream-compatible closed clients include Shadowrocket 2.2.65+, Stash and Loon; behavioral/Store reference only.
- mihomo and other multi-protocol clients are separate implementation candidates with independent licenses.

Android/iOS Store receipts, VPN lifecycle, TV support and device certification are later acceptance work and are not inferred from parser support.
