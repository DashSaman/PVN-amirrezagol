# 048 Snell — client install matrix

Reviewed: 2026-08-15

## Official clients

The canonical supported client is Surge. Current Surge manual documents:
- Snell v4/v5/v6 proxy policy;
- UDP relay for v4/v5/v6;
- Snell v6 on iOS 5.20.0+ and Mac 6.7.0+;
- optional ShadowTLS composition for supported Snell configurations;
- v6 beta warning requiring compatible client/server beta versions.

The exact current Surge app license/subscription/Store lifecycle is proprietary and belongs to the Surge product, not the Snell server download. No official Windows/Linux Snell GUI client is claimed.

## Third-party clients

`opensnell` provides GPL-3.0 community v4/v5 client/server code. Other open/multi-protocol clients may parse/implement Snell, but due vendor's explicit anti-reverse-engineering request they are interoperability evidence only unless rights/authorization are separately established.

Store receipts, device behavior and live compatibility remain later certification work, not hidden V2 completion gates.
