# 042 Hysteria v1 — client install matrix

The v1.3.5 official release/source is the canonical legacy client as well as server implementation. Release/build evidence covers major desktop/server platforms; exact mobile GUI support is not inferred from later Hysteria2 clients.

Legacy local modes from source/README: SOCKS5 TCP/UDP, HTTP/HTTPS proxy, TCP/UDP relay, Linux TCP/UDP TPROXY, Linux TCP REDIRECT, and TUN (TAP on Windows).

No current App Store/Play Store application is claimed as canonical Hysteria v1 without an exact historical version/source pin. Store/device certification is later acceptance work, not a V2 completion gate.
