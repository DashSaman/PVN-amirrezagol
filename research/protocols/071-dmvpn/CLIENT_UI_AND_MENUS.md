# DMVPN — Client / Peer UI and Menus

Reviewed: 2026-08-15

There is no canonical consumer-client UI. Spoke administration is router/infrastructure configuration.

Evidence-backed conceptual fields: hub/NHS address, tunnel/mGRE identity, NHRP network/maps/shortcut/redirect policy, routing state, IPsec/IKE identity/authentication and component diagnostics. NHRP cache/registration is runtime state, not a secret store.

A future PVNetwork orchestration UI must not merge GRE/NHRP reachability with IPsec security status. Consumer subscription/QR/store menus are N/A.
