# VXLAN — Client UI and Menus

Reviewed: 2026-08-15

No canonical consumer-client UI exists. VTEP configuration is infrastructure management.

Evidence-backed fields include VNI, underlay local/remote or multicast group, UDP destination port, physical device, learning/FDB behavior, bridge membership, MTU and statistics. Bare VXLAN has no login, QR/subscription import, certificate/cipher, MFA, kill-switch or Store onboarding contract.

UI must state that VNI separation is not cryptographic security and bare VXLAN does not encrypt/authenticate overlay traffic.
