# Cisco GETVPN — Server UI and Menus

Reviewed: 2026-08-15

Canonical management is Cisco IOS/IOS XE configuration and operational CLI, not a protocol-defined portable web panel.

Key-server surfaces include group/GKM or GDOI configuration, IPsec/group security policy, traffic ACL/policy, TEK/KEK or group-key material, rekey timers/method, authentication/IKEv2 profile where G-IKEv2 is used, GM registration/removal and cooperative-key-server/resiliency controls where supported.

Group-member surfaces include KS/group selection, registration mode, received policy/security associations, fail-close/receive-only/anti-replay behavior and diagnostics.

Cisco command/UI assets are proprietary behavior references. PVNetwork must not clone Cisco branding/UI. Consumer account/subscription/QR/Store menus are N/A.
