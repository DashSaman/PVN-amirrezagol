# innernet server UI and menus

Canonical administration is CLI, not a web UI. Evidence-backed server workflow includes `innernet-server new`, `add-cidr`, `add-peer`, `serve <interface>`, and `uninstall <interface>`. The initialization wizard configures network/CIDR/listen settings; peer creation can issue one-time invitation files and admin status. No canonical dashboard, browser panel, role-management web UI, backup wizard, responsive UI or mobile server panel is claimed. Those web-menu categories are therefore NOT-APPLICABLE to the canonical upstream UI rather than silently omitted.
