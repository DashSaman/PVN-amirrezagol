# innernet server implementations

Canonical server is `innernet-server` from `tonarino/innernet`, MIT; reviewed stable `v2.0.0` and main `1ba6154b6ebacd68dfe79c3a4f6273fd3e8dea35`. It is the coordination/control service for peers, CIDRs, associations and endpoint information. WireGuard remains the encrypted peer data plane. No separate canonical web panel, hosted SaaS control plane, or alternate server implementation is promoted by upstream; third-party forks/packages are reference-only unless independently reviewed.
